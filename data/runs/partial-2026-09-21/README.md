# 중간 저장 · 2026-09-21

팬 셀 영역 오류(E-001)를 고치려고 배치를 멈추면서, 그때까지 나온 값을 그대로 옮겨 둔 것이다.
다시 돌릴 때 버려지는 계산이 없도록 남긴다.

## 무엇이 들어 있나

`01_R0/` — 1번 케이스(빈 방, 재배단도 팬도 없는 기준선)

| 파일 | 내용 |
|---|---|
| `case.json` | 이 케이스의 조건 |
| `canopy_summary.json` | 캐노피 판정면 네 곳의 평균·표준편차·변동계수. 30초, 60초 |
| `postProcessing.tar.gz` | 원본 샘플(.raw). 점마다 좌표와 값 |
| `log.run.gz` | solver 로그 전문 |
| `log.blockMesh`, `log.topoSet`, `log.decomposePar` | 격자와 분할 기록 |

## 어디까지 갔나

- 물리 시간 600 초 중 **73 초**까지 풀었고, 저장은 30 초 간격이라 **60 초**가 마지막이다.
- 벽시계로 약 14 분, 12 분할, 컨테이너 CPU 상한 11 코어.
- 중단한 뒤 이어받기를 실제로 시험했고, 60 초 저장본에서 다시 시작하는 것을 확인했다.

## 이 값이 쓸 만한가

1번은 팬을 켜지 않는 기준선이라 E-001 의 영향을 받지 않는다. 다만 600 초까지 가지
않았으므로 아직 자리를 잡는 중인 값이다. 최종 비교에는 쓰지 않고, 진행 상황과
자릿수 확인용으로만 본다.

60 초 시점 캐노피는 아래와 같다.

| 판정면 | 평균 온도 | 평균 풍속 | 풍속 변동계수 |
|---|---|---|---|
| 아래 단 중간 높이 | 299.41 K (26.3 ℃) | 0.165 m/s | 55 % |
| 아래 단 윗면 | 299.41 K | 0.169 m/s | 57 % |
| 위 단 중간 높이 | 299.44 K | 0.184 m/s | 63 % |
| 위 단 윗면 | 299.45 K | 0.184 m/s | 63 % |

에어컨만으로는 캐노피 풍속이 0.17 m/s 안팎이다. 목표로 잡은 0.3~0.8 m/s 에 크게
못 미치고, 자리마다 편차가 55 % 를 넘는다. 팬을 다는 이유가 숫자로 보이는 셈이다.
