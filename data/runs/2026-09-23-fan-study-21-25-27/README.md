## 에어컨 위치 케이스에서 고친 것 — E-003

생성기가 케이스별 에어컨 좌표를 쓰지 않고 템플릿 위치를 복사하고 있었고, 좌표를 쓰게 고친
뒤에도 옮긴 위치에서는 취출면이 3~5 장(27 번은 한 슬롯이 0 장)만 잡혔다. `src/ac_snap.py` 로
격자에 맞춰 상자를 고른 결과 25·27 = 6/6/6/6/36(기준과 같음), 26 = 5/5/6/6/37 이다.
자세한 내용은 `docs/FAN-CFD-ERRATA.md` E-003.

## 기계

Lenovo Legion 노트북, i9-14900HX 24 코어(8P+16E)/32 스레드, RAM 64 GB. WSL2 Ubuntu-24.04
안에서 Docker 엔진(Docker Desktop 아님)으로 돌렸다. WSL 에 24 스레드·32 GB 를 주고 컨테이너
`--cpus 14` 로 묶으면 작업관리자 CPU 가 약 75 % 다.

밟은 함정 둘. ① WSL 은 붙은 세션이 없으면 VM 을 내린다 — 첫 21 번이 그렇게 죽었다.
`.wslconfig` 에 `vmIdleTimeout=-1` 을 넣고 숨김 `wsl ... sleep infinity` 세션을 상주시켰다.
② `systemctl stop` 으로 배치 유닛을 멈춰도 컨테이너는 계속 돈다 — `docker stop` 을 따로 해야 한다.
