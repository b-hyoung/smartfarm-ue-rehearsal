# 1. 모든 케이스가 공유하는 환경

**아래 27 개 케이스는 전부 이 방, 이 재배단에서 돌았다.** 케이스마다 달라지는 것은
팬 설정과 에어컨 위치뿐이다.

## 방

```
       ┌─────────────── 반타원 ───────────────┐
       │                                      │   천장 2.7 m
       │            곡면 벽 (y+)              │
       │                                      │
       │        ┌──────────────┐              │
       │        │   재배단      │  ← 방 한가운데 뒤쪽
       │        └──────────────┘              │
       │                                      │
       └────────── 평벽 y = 0 ────────────────┘
             x = −4.0            x = +4.0
```

| | 값 |
|---|---|
| 모양 | **반타원** (직육면체가 아니다) |
| 평벽 | `y = 0`, 길이 8.0 m |
| 곡면 | 반장축 a = 4.0 m, 반단축 b = 5.7 m |
| 높이 | 2.7 m |
| 바운딩박스 | 8.0 × 5.7 × 2.7 m |
| **실체적** | **96.65 m³** |
| 벽 온도 | **29 ℃ 고정** (302 K) — 단열이 아니다 |

좌표는 **CFD 좌표**다. `UE x = CFD x + 4.0`, y·z 는 같다.

## 재배단 — 전 케이스 고정

```
   z
 1.60 ┤ ░░░░░░░░░░░░░░░░  위 단 캐노피 윗면      ← 판정면
 1.475┤ ░░░░░░░░░░░░░░░░  위 단 캐노피 중간      ← 판정면
 1.35 ┤ ████████████████  위 선반면
      │
      │        (뚫림)
      │
 0.80 ┤ ░░░░░░░░░░░░░░░░  아래 단 캐노피 윗면    ← 판정면
 0.675┤ ░░░░░░░░░░░░░░░░  아래 단 캐노피 중간    ← 판정면
 0.55 ┤ ████████████████  아래 선반면
      │ ‖              ‖  기둥 (0 ~ 1.5)
 0.00 └─┴──────────────┴─ 바닥
        x −1.2      +1.2
```

| | 값 |
|---|---|
| 위치 (중심) | CFD **(0.0, 2.0)** — 전 케이스 고정 |
| 베드 | **2.40 m (가로) × 0.80 m (깊이)**, 2 단 |
| 선반면 높이 | **0.55 / 1.35 m** (간격 800 mm) |
| 선반판 · 기둥 | 50 mm · 60 mm |
| 작물층(캐노피) | 선반면 위 **0.25 m**, DarcyForchheimer 다공체 |
| 다공체 저항 | `d` 25 1/m², `f` 1.3 1/m — Zhang 외 2025 상추 |
| **맨 위** | **뚫려 있다** (문헌의 식물공장은 LED 패널로 막혀 있다) |
| 선반 표면 온도 | **29 ℃ 고정** → 캐노피에 **278 W** 주입 (의도치 않음, E-006) |

## 에어컨 — 천장 4Way 카세트

| | 값 |
|---|---|
| 기본 위치 | CFD **(0.0, 2.0, 2.7)** — **재배단 바로 위** |
| 풍량 | 25 CMM (슬롯 4 개 × 6.25) |
| 급기 온도 | 289.5 K (16.35 ℃) |
| 취출 방향 | **수직 아래** ⚠ 실물은 베인 25° (E-004) |
| 취출 속도 | **1.74 m/s** ⚠ 설계는 3.47 (E-005) |
| 리턴 | 카세트 중앙, 0.57 × 0.57 m |
| **어느 케이스에서도 끄지 않는다.** 25~30 번만 위치를 옮긴다 | |

## 물리·수치

| | 값 |
|---|---|
| 솔버 | `buoyantPimpleFoam` (과도해석, OpenFOAM v2512) |
| 난류 | 표준 k-ε |
| 시간 | 적응 Δt, `maxCo 1.0`, 30 초 간격 저장 |
| 격자 | 0.10 m, 재배단·팬 상자만 **0.05 m** |
| 셀 수 | 약 177,600 |
| 조명 발열 | **뺐다** |
| 팬 모델 | 벽면이 아니라 **유동 영역 안의 운동량 소스** |

## 판정

- **적정 대역 0.3 ~ 1.0 m/s** (Sohn 외 2023 과 같은 대역)
- **300 ~ 450 초 여섯 장을 점마다 시간평균**한 뒤 분위수를 낸다
- 범위는 재배 베드 `x ±1.2, y 1.6~2.4`

# 3. ⚠ 학습 전에 반드시

**이 데이터에는 알려진 물리 오류 셋이 27 케이스 전부에 들어 있다.**

| | 무엇이 틀렸나 |
|---|---|
| **E-004** | 에어컨이 **수직 아래**로 분다. 실물은 4Way 베인 25° |
| **E-005** | 취출면이 격자보다 좁아 2 배로 잡혀 **취출 속도가 절반**(1.74 vs 3.47 m/s) |
| **E-006** | 재배단 선반이 **29 ℃ 로 고정**돼 캐노피에 278 W 를 넣는다 |

`cases.csv` 의 `err_E004_ac_vertical` `err_E005_ac_slot_2x` `err_E006_rackwall_heat` 로
행마다 표시돼 있다. **지금은 전부 1 이다.** 자세한 내용은 `docs/FAN-CFD-ERRATA.md`.

캐노피 풍속만 보면 영향이 작다 — 에어컨만 켠 `02_R1` 의 P90 이 0.206, 팬을 켠 `05_F3` 이
1.333 로 **6.5 배** 차이다. 하지만 방 규모 재순환과 부력에는 작지 않다.

# 4. 파일

| 파일 | 한 행이 무엇인가 |
|---|---|
| `cases.csv` | **케이스 1 건** — 위 1 · 2 절의 모든 조건이 열로 (60 열) |
| `scores.csv` | **케이스 × 판정면** — P10 · P50 · P90 · 평균 · 편차 |
| `fields/<run_id>.csv` | **판정면 × 시각 × 점** — 재배 베드 안, 300~450 초. 케이스당 약 2 만 행 |

방 전체 단면과 전 시각이 필요하면 `py -m src.make_dataset --fields` →
`out/dataset/fields/` (케이스당 약 35 만 행 / 35 MB, 커밋하지 않는다).

열 설명과 읽는 예는 **`docs/DATASET.md`**.

```bash
py -m src.make_dataset            # 이 폴더를 다시 만든다
```
