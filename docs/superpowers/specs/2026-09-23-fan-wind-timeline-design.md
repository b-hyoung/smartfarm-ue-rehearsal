# 팬 바람 미리보기 — 시간별 재생 설계

2026-09-23 · `web/fan-wind.html` 에 30 초 간격 스냅샷 재생을 붙인다.

## 목적

지금 페이지는 케이스마다 300~450 초 시간평균 한 장만 보여 준다. 팬을 켠 뒤 바람이
캐노피에 퍼져 가는 과정을 보려면 시각별 장이 필요하다. 원본(`postProcessing/canopy/<t>/`)에
30 초 간격 스냅샷이 이미 있으므로 계산 없이 만들 수 있다.

## 범위

- 3D 바닥 색, 지도 두 장, 단면 두 개가 슬라이더 시각에 따라 바뀐다.
- 점수 상자·판정 문장·표는 공식 채점값(평균) 그대로 둔다. 슬라이더 옆에 그 시각 P10 만 보인다.
- 시간별 원본이 없는 케이스는 슬라이더를 끄고 문구를 띄운다.

## 데이터 — `src/make_wind_page.py`

- `tiers.t0` · `tiers.t1` 에 `frames` 를 더한다: `{"30": grid, "60": grid, ...}`.
  grid 는 기존 `g` 와 같은 49×17, 소수 3 자리, 방 밖은 null.
- 존재하는 시각만 넣는다. 평균 `g` 계산은 바꾸지 않는다.
- 경로: 윈도우 절대경로를 버리고 `REPO` 는 파일 위치에서, `ROOT` 는 환경변수
  `SF_WIND_ROOT`(기본 `~/smartfarm-cfd/cases/fan-study`)에서 받는다.
- 맥에서는 `data/runs/*/<case>/postProcessing.tar.gz` 를 한 폴더에 풀어 `SF_WIND_ROOT` 로 준다.
  이 폴더에 없는 케이스(1~6·9·10)는 `frames` 가 비고, 윈도우에서 다시 돌리면 채워진다.
- 파일 크기 약 4 MB 를 받아들인다 (접근법 A. 양자화·분리 파일은 코드가 늘어 보류).

## 화면 — `web/_wind/index.html`, `app.js`

- 3D 캔버스 아래 한 줄: 재생 버튼, `<input type=range>`, `t = 240 s · 이 시각 P10 0.18`.
- 슬라이더 눈금 = 그 케이스의 시각 목록 + 마지막 눈금 "평균". 처음 열 때와 케이스를
  바꿀 때는 "평균"이라 기존 화면과 같다.
- 재생: 0.5 초 간격으로 다음 눈금, 끝에서 처음으로. 케이스를 바꾸면 멈춘다.
- 슬라이더 변경 시 `imageOf` · `drawMap` · `profiles` · `drawProfile` 에 프레임 격자를
  넘겨 다시 그린다. 그리기 함수는 손대지 않는다. 3D 는 텍스처만 교체한다.
- "이 시각 P10" 은 프레임 값의 10 % 분위수를 JS 로 즉석 계산한다 (`score` 의 p10 과 같은 정의).
- `frames` 가 비면 슬라이더 `disabled`, 문구 "시간별 원본 없음 — 평균 한 장만".

## 산출과 검증

- `py -m src.make_wind_page --build` 로 `web/fan-wind.html` 재생성.
- 생성기: 11_S3 의 frames 시각 수 20, 격자 49×17.
- 페이지: 브라우저에서 슬라이더 이동·재생·케이스 전환·원본 없는 케이스를 눈으로 확인.
