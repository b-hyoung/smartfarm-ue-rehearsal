3문헌의 구성

최소 전력과 균일도를 같이 다룬 연구는 대부분 같은 네 단계를 쓴다.

  1. CFD 케이스 — 실험계획법으로 조건을 배치한다.
  2. 대리모델 — 응답곡면(RSM), 신경망, POD-신경망. 케이스가 적으면 RSM·가우시안 프로세스가 많다.
  3. 다목적 최적화 — NSGA-II로 파레토 해를 얻는다. 계산이 비싼 경우 베이지안 최적화.
  4. 최종안 선택과 확인 — TOPSIS 등으로 하나를 고르고 CFD로 다시 확인한다.

4우리 구성 (예정)

  1. 학습 데이터 정리 (완료, GPT 교차검증) — cases.csv의 팬 위치 열을 CFD가 실제로 쓴 fan_zones 기준으로 고쳤다. 꺼진 팬이 빠지고 흡입기는 바깥을 향한다. 학습표에는 오류(E-004~006) 표시 열을 붙였고, 풍량은 추력 환산용 명목값이다.
  2. 목표 단일 출처 — 위 기준값을 설정 파일 하나에 두고 채점기와 최적화가 같이 읽는다.
  3. 팬 데이터시트 (완료, 추정식) — W1G200-CI77-52 기준 P = P₀ + k·Q³. “팬 데이터시트” 탭.
  4. 대리모델 — 현재 운전 상황(에어컨 기준 위치, 마주보기, 15°, +0.18 m)에 맞는 13 케이스만 쓴다: 02 R1 · 03~08 F1~F6 · 09~14 S1~S6. 입력은 팬 네 대 각각의 풍량(꺼짐 = 0), 출력은 두 단의 적정 면적과 P10. 학습표 data/fan-dataset/current_subset.csv.
  5. 최적화 — 풍속 제약을 지키는 최소 전력 후보를 찾는다. 대리모델 불확실성이 큰 후보는 “미검증”으로 따로 표시한다.
한계. 모든 값은 실측이 아니라 CFD 계산값이며 E-004(에어컨 수직 취출) · E-005(취출 속도 절반) · E-006(선반 열 278 W)이 들어 있다. 여기서 찾는 최적은 이 CFD 설정의 최적이다. 실측으로 확정된 것은 방 크기뿐이다.

k · ε · 압력 — 쉬운 설명

맥에서 T7로 가져온 CFD 결과(11~14번)에서 새로 꺼낸 값들이 무엇인지 · 2026-10-06

CFD는 바람의 속도와 온도만 계산하는 게 아니다. 바람이 얼마나 출렁이는지(k), 그 출렁임이 얼마나 빨리 잦아드는지(ε), 공기를 어느 쪽으로 미는 힘(압력)도 같이 계산한다. 지금까지 PINN은 앞의 둘만 받았고, 이번에 뒤의 셋을 처음 받았다.

k와 ε를 합치면 — “섞는 힘”

출렁임은 공기를 마구 섞는다. 그래서 바람은 실제 공기보다 훨씬 끈적한 공기처럼 행동한다. 빠른 줄기와 느린 구석의 차이가 금방 섞여 줄어든다. 이 섞는 힘(난류 점성)은 k와 ε로 계산한다: 0.09 × k² ÷ ε.

  • PINN에게 k·ε 정답을 주지 않았더니, “출렁임이 없다(k = 0)”고 해 버리면 물리 시험 한 과목이 저절로 만점이 되는 꼼수를 찾았다.
  • 그 결과 PINN 속 공기는 거의 섞이지 않는 공기가 됐다. 실제(234배)와 2,000배 넘게 차이 난다.
  • 섞이지 않는 공기에서는 바람 줄기가 좁게 나가고 옆이 정체된다. 그래서 PINN이 바람 약한 구석(P10)을 실제보다 나쁘게 예측했을 가능성이 있다.

논문 정리 — RANS-PINN

팬 조건 PINN(src/ml/fan_pinn.py)이 따르는 논문 · 원문 PDF를 직접 읽고 정리 · 2026-10-06

제목RANS-PINN based Simulation Surrogates for Predicting Turbulent Flows
저자Shinjan Ghosh, Amit Chakraborty, Georgia Olympia Brikis, Biswadip Dey — Siemens Technology (미국 프린스턴)
발표ICML 2023 워크숍 “Synergy of Scientific and Machine Learning Modeling” (동료 심사), arXiv:2306.06034 (v3, 2023-08-11)
확장판“Using Parametric PINNs for Predicting Internal and External Turbulent Flows”, arXiv:2410.18917 (2024) — 같은 틀을 날개·후향 계단 유동으로 넓힘
k-ε 난류모델(산업 CFD에서 가장 많이 쓰는 2방정식 RANS)을 PINN 손실에 넣고, 레이놀즈 수를 입력으로 더해 한 번 학습한 모델이 CFD를 돌리지 않은 조건의 유동장까지 예측하게 한 연구다. 우리 문제의 “팬 풍량 → 기류장”과 구조가 같다.

1왜 이 논문인가

  • 우리 CFD(OpenFOAM buoyantPimpleFoam)도 표준 k-ε로 풀었다. 같은 난류모델을 PINN에 넣은 연구라 물리 손실이 CFD와 같은 식이 된다.
  • 매개변수형이다. 운전 조건을 입력으로 넣어 학습에 없던 조건을 예측한다 — 우리가 하려는 “팬 조합 탐색”이 바로 이것이다.
  • 저자들 스스로 “2방정식 RANS를 PINN에 넣은 연구는 아직 드물다”고 적었고, 그 공백을 채운 연구다. 앞선 Eivazi 외(2022)는 k-ε가 아니라 레이놀즈 응력을 직접 출력하는 방식이었다.

2지배방정식

식논문 표기
연속(질량 보존)∇·u = 0
운동량(RANS)ρ(u·∇)u + ∇p − μeff∇²u = 0,  μeff = μ + μt = μ + 0.09 k²/ε
k 식∇·(ρuk) = ∇·[(μ + μt/σk)∇k] + Pk − ε
ε 식∇·(ρuε) = ∇·[(μ + μt/σε)∇ε] + (C1Pε − C2ε) ε/k
상수C1 = 1.44, C2 = 1.92, σk = 1, σε = 1.3 (Launder & Spalding 1974 표준값)

원문 PDF의 ε 식 생성항 부호는 “+C2ε”로 찍혀 있으나 표준 k-ε는 “−C2ε”이다. 우리 구현은 표준식을 쓴다.

3구조와 학습법

  1. 변수마다 따로 둔 신경망 — u, p, k, ε 각각 별도 네트워크(Modulus 기본값의 Fourier Neural Operator). 입력은 모두 같다: 좌표 (x, y) + 레이놀즈 수.
  2. 예열(pre-training) — 처음에는 데이터 손실만으로 각 네트워크를 따로 학습한다. 데이터·물리 손실을 처음부터 같이 넣으면 손실이 출렁이고 수렴이 느리며 검증 오차가 크다고 보고했다.
  3. 물리 손실 추가 — 예열 뒤 PDE 손실을 넣는다. 각 PDE 항은 자기 잔차 크기의 역수로 가중해 서로 균형을 맞춘다.
  4. ε 에는 로그 손실 — 벽 근처와 전단층에서 ε가 급변하므로 ε의 데이터·PDE 손실은 로그로, 나머지는 MSE로 계산한다.
  5. 최적화 — Adam, 학습률 0.001에서 감쇠율 0.95로 줄이며 수렴할 때까지. 구현은 NVIDIA Modulus 22.03.

전체 손실은 L = Ldata + LBC + LPDE, LPDE = λ1LNS + λ2Lcont + λ3Lk + λ4Lε.

7용어집

본문의 밑줄 친 단어를 누르면 오른쪽에 같은 설명이 크게 뜬다. 패널 안 버튼이나 ← → 키로 다음 용어로 넘어간다.

용어뜻
Fourier Neural Operator푸리에 신경 연산자(FNO). 격자 위 데이터 전체를 한 번에 받아 주파수 성분으로 바꿔 계산하는 신경망. 고른 격자에 강하다.
Darcy–Forchheimer다공체(구멍 많은 물체)를 지나는 바람이 받는 저항 식. 느릴 때는 속도에 비례(Darcy), 빠를 때는 속도²에 비례(Forchheimer)하는 저항을 더한다. 우리 CFD는 상추 캐노피를 이 식으로 넣었다.
Boussinesq부시네스크 근사. 공기 밀도 차이는 무게(부력)에만 반영하고 나머지 계산에서는 밀도를 일정하게 보는 방법. 따뜻한 공기가 뜨는 효과를 넣는다.
레이놀즈 응력난류의 빠른 흔들림이 평균 흐름에 주는 추가 힘. 이걸 직접 계산하는 대신 k-ε 같은 난류모델로 근사한다.
레이놀즈 수관성력 ÷ 점성력. 흐름이 얼마나 빠르고 거친지(난류인지)를 나타내는 숫자. 이 논문에서는 유입 속도를 바꾸는 것과 같다. 우리 문제에서는 팬 풍량이 이 역할을 한다.
매개변수형운전 조건(레이놀즈 수, 팬 풍량 등)을 신경망 입력에 넣어, 한 번 학습한 모델로 여러 조건을 예측하게 만든 형태.
2방정식난류를 두 개의 추가 식(k 식, ε 식)으로 나타내는 난류모델 종류. k-ε가 대표다.
k-ε가장 널리 쓰는 난류모델. 난류 에너지 k와 그 에너지가 사라지는 속도 ε 두 값을 따로 풀어 난류의 효과(난류 점성)를 계산한다. 우리 OpenFOAM CFD도 이걸 썼다.
난류모델눈에 안 보일 만큼 작은 소용돌이를 다 계산하지 않고, 그 평균 효과만 식으로 넣는 방법.
RANS레이놀즈 평균 나비에-스토크스 식. 흔들리는 난류를 시간 평균해서 평균 흐름만 푸는 방식. 산업용 CFD 대부분이 이것이다.
PINN물리 정보 신경망. 데이터만 외우게 하지 않고, 유체 방정식을 얼마나 어기는지도 벌점(손실)으로 줘서 물리 법칙을 지키게 학습시킨 신경망.
지배방정식그 현상을 지배하는 기본 식. 공기 흐름에서는 질량 보존, 운동량(힘의 균형), 에너지 식.
연속연속 방정식 = 질량 보존. 어떤 공간에 들어온 공기량과 나간 공기량이 같아야 한다는 식.
운동량힘의 균형 식(뉴턴 제2법칙의 유체판). 압력, 점성, 관성, 외부 힘이 공기를 어떻게 움직이는지.
유효 점성공기 자체의 끈적임(분자 점성) + 난류가 섞어 주는 효과(난류 점성). μ_eff = μ + μ_t.
난류 점성난류가 운동량을 섞는 효과를 끈적임처럼 표현한 값. k-ε에서는 0.09 × k² / ε.
생성항평균 흐름의 속도 차이(전단)에서 난류 에너지가 새로 만들어지는 양.
상수실험으로 정해 둔 숫자. 표준 k-ε는 1974년 Launder & Spalding 값을 그대로 쓴다.
유동장공간 각 점에서의 바람 속도·압력 분포 전체.
예열pre-training. 처음에는 데이터만 맞추게 학습해 대략 맞는 상태를 만든 뒤 물리 손실을 넣는 방법. 처음부터 다 넣으면 학습이 불안정하다.
데이터 손실신경망 예측이 CFD 값과 얼마나 다른지 잰 벌점.
물리 손실신경망 예측이 지배방정식을 얼마나 어기는지 잰 벌점. PDE 손실이라고도 한다.
