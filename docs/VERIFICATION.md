## 1. 가장 중요한 검증 — V7 종단 대조

앞의 V1~V5는 전부 **내부 일관성**만 봅니다. 데이터가 자기모순 없이 예쁘게 틀려도
전부 통과합니다. 그래서 **원본 OpenFOAM 값과 직접 대조**하는 항목을 넣었습니다.

| 지점 | UE 좌표 | 원본 probes (℃) | 내보낸 CSV (℃) | 오차 |
|---|---|---|---|---|
| A 에어컨 아래 | (4.0, 2.0) | 20.53 | 20.69 | 0.16 |

**최대 오차 0.16 K.** 이 하나가 통과하면 아래가 동시에 검증됩니다:

- 좌표 이동 `x + 4.0` (CFD −4~4 → UE 0~8)
- 프레임 선택 (`frame_14` = t 900초)
- 단위 (K 유지, m 유지)
- `CellDatatoPointData` 보간이 값을 망가뜨리지 않음

A의 오차가 유독 큰 것(0.16 K)은 그 지점이 냉기 제트 한가운데라 **공간 구배가 가파르기**
때문입니다. 셀→점 보간에서 가장 손해 보는 위치입니다. 예상된 편차입니다.

**V4-b 81%** — 취출 슬롯 링에서 19%가 위로 향합니다. 링 반경(0.30~0.62 m)이
중앙 리턴(r<0.285)과 슬롯 사이 경계를 일부 물었기 때문으로 보이지만,
보간된 점이라 정확한 패치 구분이 안 됩니다. **패치 라벨을 CSV 에 넣으면 깔끔해집니다.**

**V1-c 차이 0.000 K** — 소수점 셋째 자리까지 완전 일치. 케이스가 대칭이라 맞는 결과지만,

모두 x=4.0 기준 대칭이라 수치적으로도 대칭이 유지되는 것이 맞습니다.

## 5. ⚠ 해석의 한계 — 화면이 보여주지 않는 것

**아래 셋은 검증으로 못 잡습니다. 데이터가 아니라 모델의 한계입니다.**

### 5-1. 재배단이 CFD 에 없습니다
화면에는 재배단 8세트가 서 있지만, **유동은 빈 방 기준으로 계산된 것**입니다.
실제로는 선반이 기류를 막아 큰 순환 하나가 여러 개로 쪼개지고, 단 사이 온도차가
지금(0.3~0.6 ℃)보다 훨씬 커집니다.

→ 재배단 반입 시 `snappyHexMesh` 로 형상을 넣어 **다시 풀어야** 합니다.
   셀이 6~20배로 늘어 케이스당 20~50시간이 예상됩니다.

### 5-2. 벽 온도 29 ℃ 고정 가정
튜토리얼(`comfortHotRoom`)에서 딸려온 값이고 **근거가 없습니다.**
이 값이 정상상태 실내 온도를 좌우합니다 (손계산상 벽 5 ℃ 차이 → 실내 2.3 ℃ 차이).

### 5-3. 취출 방향이 수직 아래 — 실측에서 드러난 오류
```
0.orig/U:  inletX*/Y*  value uniform (0 0 -3.47)   ← 똑바로 아래
```
실제 4Way 카세트는 **베인이 바깥·수평에 가깝게 뿜습니다.** 유닛 바로 아래는
취출이 아니라 **리턴**입니다. 현재 결과의 "에어컨 아래가 가장 차갑다"는 예측은
이 잘못된 경계조건이 만든 인공물일 가능성이 큽니다.

→ 베인 각도 실측 후 `(cosθ, 0, −sinθ)` 방향으로 교체 필요.

## 6. 자동화에서 막힌 것

### 6-1. Niagara — 파이썬으로 저작 불가
```
NiagaraSystem 에셋 생성                     ✅ 가능
NiagaraDataInterfaceArrayFunctionLibrary    ✅ 배열 주입 함수 존재
NiagaraSystem 의 User 파라미터 추가/노출     ❌ 파이썬 API 없음
```
`set_niagara_array_vector` 로 위치·속도 배열을 밀어넣으려면 시스템에 **User 배열
파라미터가 미리 저작돼 있어야** 합니다. 그 저작이 파이썬에 노출돼 있지 않습니다.

**대안으로 O5-A(입자 이류)를 구현했습니다** — 실제 속도장을 RK2 로 적분해 궤적을
만들고 UE 는 그리기만 합니다. 물리적으로는 오히려 더 정직합니다.

Niagara 로 가려면 **사람이 한 번** 해야 할 일:
1. Content Browser → Niagara System (빈 것) 생성
2. User 파라미터 추가: `User.Positions` (Vector Array), `User.Colors` (LinearColor Array)
3. 이미터에서 Sample 해 파티클 배치
4. 그 뒤로는 `sf_niagara.py` 가 배열을 밀어넣어 자동화 가능

### 6-2. 에디터 뷰포트 캡처가 불안정
`take_high_res_screenshot` 은 비동기라 파일이 안 떨어질 때가 잦고,
`HighResShot` 콘솔 명령도 마찬가지였습니다. **뷰포트 리얼타임이 꺼져 있으면
렌더 틱이 안 돌아** 창을 캡처해도 이전 프레임이 찍힙니다.

```python
les = unreal.get_editor_subsystem(unreal.LevelEditorSubsystem)
les.editor_set_viewport_realtime(True, les.get_active_viewport_config_key())
```
이걸 켜야 갱신됩니다. (인자 순서는 `(bRealtime, key)`)
