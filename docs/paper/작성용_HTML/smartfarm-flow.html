03 · SEQUENCE

시퀀스 다이어그램

시스템 구성도가 ‘무엇이 연결됐는가’라면, 시퀀스는 ‘누가 어떤 순서로 처리하는가’를 보여줍니다. 이 예시는 보존된 CFD 결과를 재생하는 경로입니다.

순서사용자 / 실행자CFD · 변환 모듈언리얼
1공간 및 냉방 조건 설정해석 조건 준비공간 모델 준비
2CFD 실행 요청시간별 온도·속도장 계산대기
3계산 완료 후 데이터 추출프레임 CSV 및 파생 데이터 생성대기
4데이터 적용·시퀀스 구성변환 데이터 전달공간에 데이터 반영
5재생·화면 확인—시간에 따른 장면 재생

이 표는 처리 순서를 설명한 시퀀스 초안입니다. 자동으로 한 번에 실행되는 시스템이라는 뜻은 아니며, 논문용 UML을 만들 때 실제 실행 경로를 확인해야 합니다.

06 · EVALUATION

시스템 프로세스와 모듈별 결과

CFD 계산

출력: 시간별 온도·속도·압력장. 조건과 계산 성공 여부를 확인합니다.

변환

출력: 프레임 CSV와 파생 데이터. 프레임 수, 단위, 좌표계, 누락 여부를 확인합니다.

언리얼 재생

출력: 공간 시각화와 시간별 화면. 같은 시점의 입력 데이터와 화면이 대응하는지 확인합니다.

정확도와 처리 속도는 이렇게 나누어 평가해요

평가 항목비교하거나 측정할 것현재 쓸 수 있는 상태
물리적 정확도실제 센서 온도·풍속과 CFD 값을 같은 위치·시각에서 비교. MAE, RMSE 등 사용 가능실측 비교 필요 저장소에는 현장 실측 검증이 없다고 기록
데이터 전달 정확성원본 CFD와 변환 CSV의 좌표·온도·속도 차이 및 시간 정렬 확인선정 케이스 재확인 필요 변환기 대조 기록은 있으나 현장 정확도와 다름
화면 반영 정확성선정 지점과 시점의 CSV 값이 언리얼의 위치·색상 범례와 맞는지 확인검증 설계·측정 필요
처리 속도CFD 계산, CSV 변환, 언리얼 구성·재생을 별도 측정하고 PC 사양·데이터 크기 기록같은 조건으로 측정 필요 문서의 2시간 43분은 특정 계산 사례이며 전체 시스템 지연이 아님

구분: CFD와 CSV가 일치하면 데이터 전달 확인입니다. 실제 농장의 센서와 일치하는지를 확인해야 물리적 정확도를 말할 수 있습니다. 측정 전에는 정확도나 속도를 만들어 쓰지 않습니다.

결과 문장 틀
“선정한 [조건]에서 [N]개 시점을 변환하였으며, [위치·시간 일치 검사]를 수행하였다. 변환 처리 시간은 [측정값]초였고, 측정 환경은 [하드웨어·소프트웨어]이다.”
