# 스마트팜 논문 작성 자료

`논문_열기.cmd`를 두 번 클릭하면 Chrome에서 기존 미리보기/입력 화면이 열립니다. `열기.html` 또는 `작성용_HTML/index.html`을 Chrome에 직접 끌어 넣어도 됩니다.

- `스마트팜_논문_통합초안.docx`: 편집 가능한 Word 초안. 개발 환경은 Word 표입니다.
- `논문_전체보기.html`: 지금까지 합의한 본문, 그림 1·2, 표 1의 통합 보기입니다.
- `작성용_HTML/`: 기존 작성 화면, 참고 논문 분석, 전체 흐름 자료입니다.
- `절별자료/`: 바탕화면에서 모은 절별 HTML·TXT·SVG·PNG 및 확인 기록입니다.
- `원고/`: 편집기 백업 JSON과 구조화 원고입니다.
- `템플릿/`: 제공받은 원본 ICIot_Template.docx입니다.
- `작성도구/`: 절별 자료와 Word를 만드는 스크립트입니다.
- `검토메모.txt`: 미작성 부분, 실험 환경 확인 및 제출 전 점검 사항입니다.

본문·그림은 한국어 초안이며 결과/논의/결론을 채우고 영어로 전환한 다음 3쪽 제한에 맞춰 다듬어야 합니다. 개발 환경 표는 현재 장비 기준입니다.

Git 저장 위치는 기존 `smartfarm-ue-rehearsal` 저장소의 `docs/paper/`입니다. 바탕화면 폴더는 작업용 사본이며 자동 Git 동기화는 하지 않습니다. 브라우저 편집 내용도 백업 파일로 저장한 후 커밋해야 합니다.
